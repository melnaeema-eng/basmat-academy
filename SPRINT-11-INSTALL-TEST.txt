SPRINT 11 — COMMERCE & PRODUCTION CLOSURE
==========================================
FINAL FUNCTIONAL SPRINT before production.

INCLUDED
--------
1. Shopping Cart
   /cart
   Paid course page now has Add to Cart.
   IMPORTANT: the existing payment architecture is course-based, so Sprint 11 keeps one secure checkout/payment per course instead of faking one combined payment.

2. Purchase History + Invoices
   /purchases
   Automatic invoice/order record after a payment becomes PAID.
   Existing paid payments are backfilled safely.
   Invoice numbers: BNA-YYYY-XXXXXX.
   Print / Save PDF through browser print.

3. Refund Workflow
   Student: /refunds
   Admin: /admin/refunds
   Student requests refund only for PAID purchase.
   Admin: approve / reject / mark processed.
   IMPORTANT: "processed" means the admin has actually refunded money in the bank/payment provider. Sprint 11 does NOT pretend to reverse external money automatically.

4. Email Notifications
   Database email outbox queues payment/refund transactional emails.
   Admin: /admin/email-outbox
   Edge Function: process-email-outbox
   Uses Resend API.
   Email is not enabled until RESEND_API_KEY and ACADEMY_FROM_EMAIL are configured and the function is deployed.

5. SEO
   Base description, robots and OpenGraph site metadata.
   PageMeta reusable component added.

6. Production Security
   RLS on all Sprint 11 commerce tables.
   anon access revoked on private commerce tables.
   Refund/order writes go through controlled RPC/policies.
