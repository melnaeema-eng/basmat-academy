SCHOOL S5 BIG — FINANCE + HR + PAYROLL
======================================

يشمل:
- الأقسام والموظفين.
- ربط الموظف بالمعلم عند الحاجة.
- الراتب الأساسي + بدل السكن + النقل + بدلات أخرى + خصم ثابت.
- الصندوق والحساب البنكي.
- ربط دفعات الطلاب تلقائيًا بسجل التحصيل.
- الإيرادات الأخرى.
- المصروفات.
- Ledger موحد.
- Payroll Run شهري.
- صرف الرواتب وتسجيلها تلقائيًا كمصروف.
- Reversal للقيود بدل تعديل السجل القديم.
- Adjustment.
- Dashboard مالي حسب فترة.
- Collections / Income / Expenses / Salaries / Net.
- School Admin RLS.

ROUTES:
-------
/school/admin/employees
/school/admin/payroll
/school/admin/accounting

TEST:
-----
1) /school/admin/employees
أضف موظفًا براتب وبدلات.

2) /school/admin/payroll
أنشئ مسير الشهر.
تأكد أن Net Salary صحيح.
صرف المسير من الصندوق أو البنك.

3) /school/admin/accounting
سجل إيرادًا آخر.
سجل مصروفًا.
راجع Ledger.
جرب Reverse على قيد تجريبي.

4) /school/admin/finance
سجل دفعة طالب جديدة.
ارجع /school/admin/accounting
يجب أن تظهر كـ fee_collection تلقائيًا.

5) راجع الملخص المالي:
Collections
Other Income
Expenses
Salaries
Net
