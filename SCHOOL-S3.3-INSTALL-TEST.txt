SCHOOL S3.3 — EDIT STUDENTS & PARENTS + EMAIL POLICY
=====================================================

NO SQL.

PARENT
------
- Parent Email is REQUIRED.
- Edit button for every Parent.
- Edit:
  name, email, mobile, WhatsApp, national ID, occupation,
  address, active status, Auth User ID.

STUDENT
-------
- Edit button for every Student.
- Student Email policy:

  KG / الروضة:
  Email optional.

  Primary Grade 1–3:
  Email optional.

  From Primary Grade 4 and above:
  Email REQUIRED.

  This includes:
  P4, P5, P6
  M1, M2, M3
  S1, S2, S3

- During Academic Enrollment, if Grade 4+ is selected and
  Student has no email, enrollment is blocked until Student
  data is edited and email is added.

- Auth User ID is used to link Student Portal login.
- If Grade 4+ has email but Auth User ID is not linked yet,
  Admin receives a clear warning and may link Auth shortly after.
