SPRINT 9 — PROFESSIONAL ACADEMY FINAL LAYER
============================================
Baseline: Sprint 8 stable project + StudentDetails hotfix.

INCLUDED
--------
1) INSTRUCTOR DASHBOARD
   - Admin > Instructors can link an instructor profile to an Auth User ID.
   - Linked instructor sees "Instructor Dashboard" in user menu.
   - /instructor/dashboard
   - Own courses, enrollments, ratings, reviews and open Q&A.

2) COURSE Q&A
   - /qa/<course-id>
   - Enrolled students can ask questions and reply.
   - Linked instructor/Admin can answer.
   - Instructor answer changes question state to answered.
   - Q&A link added inside Learning page.

3) NOTES + BOOKMARKS
   - Inside each learning lesson:
     Notes panel.
     Bookmarks panel.
   - Data is private per student using RLS.
   - Notes/bookmarks remain when returning later.

4) ADVANCED EXAMS
   Admin:
   - Duration in minutes.
   - Randomize question order.
   - Show correct answers after submission.

   Student:
   - Countdown timer.
   - Auto-submit at 00:00.
   - Optional answer review after submission.
   - Existing certificate=no-retake behavior remains.

5) COUPONS / DISCOUNTS
   Admin:
   /admin/coupons
   - Percent or fixed SAR.
   - Start/end date.
   - Max uses.
   - All courses or selected courses.

   Checkout:
   - Coupon code field for BANK TRANSFER.
   - Server-side coupon validation.
   - Original price / discount / final price.
   - Payment stores coupon_id, original_amount, discount_amount.
   - Coupon use count increments when payment becomes paid.

   IMPORTANT:
   Sprint 9 intentionally does NOT apply coupons to PayPal.
   PayPal pricing is generated by the Edge Function and must not be faked in React.
   Coupon support for PayPal can be added later by updating the PayPal Edge Function.

6) ADVANCED ANALYTICS
   /admin/advanced-analytics
   - Students
   - Courses
   - Enrollments
   - Certificates
   - Revenue
   - Completion rate
   - Per-course enrollments
   - Average progress
   - Certificates
   - Ratings/reviews
   - Revenue

DATABASE
--------
Sprint 9 is additive.

It adds:
- instructors.user_id
- course_questions
- course_answers
- lesson_notes
- lesson_bookmarks
- advanced exam fields
- coupons
- coupon_courses
- payment coupon/discount fields
- instructor/analytics/coupon RPCs

It does NOT rebuild existing:
profiles / courses / lessons / enrollments / payments / certificates / notifications.
