SCHOOL SYSTEM ACCESS FINAL V4
=============================

الهدف:
إغلاق ملف الدخول والصلاحيات بالكامل قبل الإنتاج.

القواعد النهائية:
--------------
1) /login
   الأكاديمية فقط.

2) /school/login
   المدرسة فقط.

3) المستخدم لا يرى إلا الأدوار المرتبطة فعليًا بحسابه.

4) Teacher / Parent / Student
   أدوار Identity تلقائية من:
   school_teachers.auth_user_id
   school_parents.auth_user_id
   school_students.auth_user_id

5) School Admin / Finance / HR / Admissions / Student Affairs / Employee
   من school_staff_roles.

6) نفس الحساب يمكن أن يكون:
   School Admin + Teacher + Parent
   وهذا طبيعي.

7) لا نجعل Admin = Student تلقائيًا.
   إذا أردنا اختبار بوابة طالب، ندخل بحساب الطالب الحقيقي.

صفحات الإدارة:
-------------
/school/admin/access-management
إدارة صلاحيات الموظفين.

/school/admin/portals
دليل جميع بوابات النظام وحالة صلاحية الحساب الحالي.
