SCHOOL S10 BIG
REPORT CARDS + ANNUAL RESULTS + PROMOTION + CERTIFICATES + TRANSCRIPT
=====================================================================

BASELINE:
---------
S9 + Admission No FeePlan Hotfix

يشمل:
------
1) بطاقات النتائج الفصلية
   - بناء بطاقات الفصل الدراسي 1/2/3 لفصل كامل.
   - المعدل.
   - الحضور والغياب.
   - Pass / Fail.
   - نشر للطالب.
   - منع نشر البطاقة إذا توجد رسوم غير مسددة، إلا عند وجود Financial Clearance.

2) النتيجة السنوية
   - تجميع درجات جميع امتحانات العام.
   - حساب Total / Max / Average.
   - فحص المواد الراسبة حسب pass_mark في school_grade_subjects.
   - PASS فقط إذا:
     Average >= 50%
     AND failed_subjects = 0
   - ترتيب الطالب داخل الفصل.
   - نشر النتيجة.
   - منع نشر النتيجة السنوية إذا توجد رسوم غير مسددة.

3) الترفيع السنوي
   - Promote.
   - Repeat Year.
   - Graduate.
   - Transfer.
   - لا يسمح بترفيع طالب نتيجته السنوية ليست PASS.
   - لا يسمح بالترفيع إلى نفس العام الدراسي.
   - لا يسمح بالتخرج إلا من آخر صف.
   - إنشاء Enrollment جديد للعام التالي.
   - حفظ Promotion History كامل.

4) Bulk Promotion
   - بناء نتائج الفصل كله.
   - ترفيع الطلاب الناجحين فقط.
   - الطلاب الراسبون/المسودة لا يتم ترفيعهم.
   - اختيار العام والفصل التالي.

5) معلم الصف — المنهج العربي
   - عند Bulk Promotion:
     P1 -> P2: معلم الصف يتحرك مع نفس الدفعة.
     P2 -> P3: معلم الصف يتحرك مع نفس الدفعة.
     بعد P3: دورة معلم الصف تصبح Completed.
   - هذا يحافظ على قاعدة "معلم الصف" التي تم اعتمادها.

6) الشهادات
   - Completion Certificate.
   - Promotion Certificate.
   - Graduation Certificate.
   - رقم شهادة تلقائي:
     NAJ-CERT-YYYY-XXXXXX
   - Verification Code تلقائي.
   - QR حقيقي في بوابة الطالب.
   - صفحة تحقق عامة.
   - إلغاء الشهادة Revocation بدون حذف السجل.
   - لا تصدر شهادة نجاح/تخرج إذا النتيجة ليست PASS.
   - لا تصدر شهادة إذا توجد رسوم غير مسددة إلا عند وجود Financial Clearance.

7) كشف الدرجات Transcript
   - تاريخ الطالب لكل السنوات.
   - العام الدراسي.
   - الصف.
   - المنهج.
   - المواد.
   - الدرجة / الدرجة القصوى / النسبة.
   - المعدل السنوي.
   - حالة النجاح والترفيع.
   - طباعة.
   - Student self access.
   - Parent access foundation عبر can_receive_results.
   - School Admin access.

8) Student Portal
   /school/student/academic-records

   يحتوي:
   - النتائج السنوية.
   - بطاقات الفصول.
   - كشف الدرجات.
   - الشهادات.
   - QR للتحقق.
   - الطباعة.

9) Public Certificate Verification
   /school/verify-certificate/VERIFICATION_CODE

10) Admin
   /school/admin/academic-records

   يحتوي:
   - Build Annual Results.
   - Build Term Report Cards.
   - Publish.
   - Bulk Promotion.
   - Individual Promote.
   - Repeat.
   - Graduate.
   - Issue Certificate.
   - Transcript.
   - Certificate Revocation.

TEST 3 — PROMOTION:
-------------------
مهم:
قبل Bulk Promotion يجب أن يكون:
- العام الدراسي التالي موجودًا.
- الفصل للصف التالي موجودًا في العام التالي.

مثال:
Grade 4 / A / 2026-2027
->
Grade 5 / A / 2027-2028

اضغط:
ترفيع الناجحين

Expected:
- PASS students -> Enrollment جديد.
- Failed/Draft -> لا يترفع.
- Enrollment القديم -> Completed.
