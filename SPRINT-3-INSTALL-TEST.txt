============================================================
BASMAT ALNAWABIGH ACADEMY
SPRINT 3 - PAYMENTS & CHECKOUT
============================================================

SPRINT GOAL
-----------
1) Free course (price = 0): enroll immediately.
2) Paid course (price > 0): NEVER enroll directly; go to Checkout.
3) Al Rajhi bank transfer: student uploads receipt -> Admin reviews -> approval creates enrollment.
4) PayPal: secure server-side create/capture flow is included and stays inactive until Sandbox credentials are added.
5) STC Pay / Al Rajhi online gateway: structure is reserved, but no fake gateway is enabled in this Sprint.

IMPORTANT
---------
- Run the SQL before testing payments.
- Bank-transfer receipts use a PRIVATE bucket named payment-receipts.
- PayPal Secret must NEVER be placed in React/.env. It belongs only in Supabase Secrets.

============================================================
G) PAYPAL - READY BUT REQUIRES SANDBOX CREDENTIALS
============================================================

Until PayPal credentials are configured, Checkout shows that PayPal setup is pending.
Bank transfer remains fully testable.

When you obtain PayPal Sandbox credentials:

1. Add ONLY the public Client ID to your project .env:

VITE_PAYPAL_CLIENT_ID=YOUR_PAYPAL_SANDBOX_CLIENT_ID

2. Keep Client Secret ONLY in Supabase Secrets.
Never put the Secret in VITE_ variables.

3. From PowerShell in the project folder, if Supabase CLI is not available:

npm install -D supabase

4. Login/link Supabase (one-time):

npx supabase login
npx supabase link --project-ref pxbtwjuerndgmppicumr

5. Set PayPal secrets:

npx supabase secrets set PAYPAL_CLIENT_ID=YOUR_SANDBOX_CLIENT_ID
npx supabase secrets set PAYPAL_CLIENT_SECRET=YOUR_SANDBOX_SECRET
npx supabase secrets set PAYPAL_ENV=sandbox

6. Deploy secure Edge Functions:

npx supabase functions deploy create-paypal-order
npx supabase functions deploy capture-paypal-order

7. Restart Vite:

npm run dev

PAYPAL TEST EXPECTED:
- Paid course -> Checkout -> PayPal.
- PayPal Sandbox button appears.
- Server creates order from the course price in Supabase (not from browser price).
- Server captures/validates the payment.
- Only after COMPLETED capture, enrollment is created.

For LIVE later:
- Replace Sandbox credentials with Live credentials.
- Set PAYPAL_ENV=live.
- Test again before production.
