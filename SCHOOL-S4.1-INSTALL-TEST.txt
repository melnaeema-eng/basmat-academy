SCHOOL S4.1 — EXAM FILTER CORRECTION
====================================
هذا تصحيح S4 فقط. لا يوجد SQL جديد.

تم إصلاح صفحة الامتحانات لتعمل بالترتيب:
1. المنهج
2. الصف / المستوى
3. الفصل
4. المادة

التصحيح:
- لم يعد حقل "الفصل" يعرض KG1 وKG2 وKG3 وGrade 1 معًا.
- بعد اختيار المنهج تظهر فقط الصفوف التي لها Class Sections في هذا المنهج.
- بعد اختيار الصف تظهر فقط فصول هذا الصف والمنهج (A/B/C...).
- المواد تأتي من school_grade_subjects للصف + المنهج + العام الدراسي الحالي.
- تغيير المنهج أو الصف يصفر الاختيارات التابعة حتى لا يبقى اختيار قديم خاطئ.
