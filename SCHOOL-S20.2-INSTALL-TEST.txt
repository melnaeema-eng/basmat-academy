SCHOOL S20.2 — FINANCE UI COMPLETE
==================================

هذه الحزمة تكمل واجهة S20.1.
لا يوجد SQL جديد.

المسار:
-------
/school/admin/finance

التبويبات:
----------
1) الملخص المالي
2) رسوم الطلاب
3) خطط الرسوم
4) الإيصالات
5) الحسابات والمصروفات
6) الرواتب

يشمل من الصفحة:
- اختيار الطالب.
- عرض إجمالي الرسوم والخصومات والمدفوع والمتبقي.
- تطبيق خصم الأشقاء 10%.
- إنشاء الأقساط.
- تسجيل دفعة.
- إصدار Receipt No تلقائي.
- عرض/طباعة الإيصالات.
- خطط الرسوم.
- تسجيل إيراد.
- تسجيل مصروف.
- عرض القيود المالية.
- إنشاء مسير الرواتب.
- صرف الرواتب.

INSTALL:
--------
Ctrl+C

cd C:\projects\basmat-academy

Copy-Item ".\src" ".\src-before-school-s20-2" -Recurse -Force

Expand-Archive -Path "$env:USERPROFILE\Downloads\SCHOOL-S20.2-FINANCE-UI-COMPLETE.zip" -DestinationPath "C:\projects\basmat-academy" -Force

ثم:
npm run dev

افتح:
/school/admin/finance

TEST:
-----
A) Dashboard:
يجب أن ترى:
تحصيل الطلاب / الإيرادات / المصروفات / الإيصالات / الحسابات / الرواتب.

B) رسوم الطلاب:
اختر طالبًا.
يجب أن يظهر:
Gross / Discounts / Paid / Balance.

C) خصم الأشقاء:
اختر طالبًا له أخ/أخت لنفس ولي الأمر.
اضغط "تطبيق خصم الأشقاء 10%".
Expected:
رسالة Applied + الخصم يظهر في الملخص.

D) دفعة وإيصال:
اختر قسطًا.
أدخل المبلغ.
اضغط تسجيل وإصدار إيصال.
Expected:
Receipt مثل:
RCPT-2026-001001

E) الإيصالات:
افتح تبويب الإيصالات.
Expected:
الإيصال الجديد يظهر.

F) الحسابات والمصروفات:
سجل Income تجريبي ثم Expense تجريبي.
Expected:
القيود تظهر.

G) الرواتب:
أنشئ Payroll Run ثم راجعه.
لا تصرف الرواتب الفعلية إلا إذا كانت بيانات الموظفين والعقود صحيحة.

BUILD:
------
npm run build
git add .
git commit -m "School S20.2 complete finance UI"
git push
