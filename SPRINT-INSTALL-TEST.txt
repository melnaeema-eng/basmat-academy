SPRINT 7 — ACADEMY PROFESSIONAL PLATFORM
========================================
Baseline: Sprint 6 (stable)

MAIN FEATURES
-------------
1) ADMIN MOBILE
   - Clear "Back to Website" icon in the mobile Admin header.
   - Logout icon remains visible.
   - Desktop sidebar still has Website + Logout.

2) INSTRUCTOR PROFILES
   Admin:
   /admin/instructors
   - Add / Edit / Delete instructor.
   - Professional title, bio, specialties, photo URL, LinkedIn, website.
   - Link an instructor profile to a course from Add/Edit Course.

   Public:
   /instructors
   /instructors/:id
   - Instructor profile + linked courses.

3) LEARNING PATHS
   Admin:
   /admin/learning-paths
   - Create a learning path.
   - Add multiple existing courses in an ordered path.
   - Publish / Draft.

   Public:
   /paths
   /paths/:id

4) LIVE COURSES / HYBRID
   Admin:
   /admin/live-sessions
   - Course
   - Zoom / Teams / Google Meet / Other
   - Start / End time
   - Meeting URL
   - Scheduled / Completed / Cancelled
   - Notes

   Student:
   /live-sessions
   - Only sessions for courses the logged-in student is enrolled in.
   - Upcoming and previous sessions.
   - Join Session button.

5) COURSE PREVIEW
   Admin already has "Free Preview" checkbox in Lessons.
   Sprint 7 now uses it on Course Details.
   - Preview lesson opens video/file before enrollment.
   - Non-preview media URLs are NOT returned by the public curriculum RPC.

6) CHECKOUT UX
   - Professional bank transfer / PayPal layout.
   - Correct LTR display for IBAN, account number and amount.
   - Rejected receipt message retained.
   - mada / Cards / STC Pay shown as "ready for gateway activation",
     NOT as a fake working payment method.

7) ADMIN REPORTS
   /admin/reports
   - Students
   - Courses
   - Exams
   - Certificates
   - Paid amount
   - Pending amount
   - Top courses by enrollment
   - Recent certificates/payments
   - CSV export

8) HOME / NAVIGATION
   - Learning Paths and Instructors added to navigation.
   - Home can show published Paths/Instructors once Admin creates them.
   - Student menu includes Live Sessions.

DATABASE CHANGES
----------------
Sprint 7 is additive.

It creates:
- public.instructors
- public.learning_paths
- public.learning_path_courses
- public.live_sessions
- courses.instructor_id
- safe public curriculum RPC

It DOES NOT delete or rebuild:
- profiles
- payments
- enrollments
- lessons
- exams
- certificates
- notifications
- reviews
- wishlist

PRE-INSTALL BACKUP
------------------
1) Stop server:
Ctrl + C

2) PowerShell:
cd C:\projects\basmat-academy

3) Backup current Sprint 6 source:
Copy-Item ".\src" ".\src-before-s7" -Recurse -Force

INSTALL
-------
4) Extract:
Expand-Archive -Path "$env:USERPROFILE\Downloads\SPRINT-7-ACADEMY-PROFESSIONAL.zip" -DestinationPath "C:\projects\basmat-academy" -Force

5) Supabase > SQL Editor:
Run ONLY:
C:\projects\basmat-academy\supabase\SPRINT-7.sql

Expected:
Success. No rows returned

Run:
C:\projects\basmat-academy\supabase\SPRINT-7-VERIFY.sql

7) Start:
npm run dev
