SPRINT 6 — UDEMY EXPERIENCE + MOBILE FIXES
==========================================
GOAL
----
Make the academy experience closer to a mature course marketplace while preserving
the stable Sprint 5.4 payment, enrollment, exams and certificates.

INCLUDED
--------
1. Admin mobile logout button is visible in the mobile header.
2. Course Details rebuilt in marketplace/Udemy style:
   - Course headline + instructor + level
   - Rating summary
   - Price/enroll card
   - Wishlist
   - Course curriculum
   - Instructor block
   - Student reviews
   - Enrolled student can submit/update one review
3. Wishlist page.
4. Student Learning Dashboard /student:
   Continue Learning + My Courses + Alerts + Payments + Certificates + Wishlist.
5. Course Catalog sorting:
   Newest / Price Low-High / Price High-Low.
6. Learning player improvements:
   - Keeps last lesson
   - Previous / Next
   - Progress
   - Direct MP4 marks complete when video reaches the end
   - Lesson attachment panel when a file URL exists.
7. Mobile/Desktop preserved.

DATABASE
--------
This Sprint DOES include one SQL file:
supabase\SPRINT-6.sql

It ONLY creates:
- course_wishlist
- course_reviews
- public review RPC

It does NOT modify payments, profiles, enrollments, exams or certificates.

INSTALL
-------
1) Stop dev server:
Ctrl + C

2) Backup current stable source:
cd C:\projects\basmat-academy
Copy-Item ".\src" ".\src-before-s6" -Recurse -Force

3) Extract:
Expand-Archive -Path "$env:USERPROFILE\Downloads\SPRINT-6-UDEMY-EXPERIENCE.zip" -DestinationPath "C:\projects\basmat-academy" -Force

4) Supabase > SQL Editor:
Run ONLY:
C:\projects\basmat-academy\supabase\SPRINT-6.sql

5) Start:
npm run dev

SMOKE TEST FIRST
----------------
Open in this order:
/
 /courses
 /courses/<COURSE-ID>
 /login
 /admin/dashboard

If one is blank, STOP. Do not continue.

TEST COURSE MARKETPLACE
-----------------------
1. Open a course.
2. Course detail page must show:
   image / price / instructor / curriculum / rating / wishlist.
3. Guest presses Wishlist -> login.
4. Student presses Wishlist -> heart state changes.
5. /wishlist shows the saved course.

TEST REVIEWS
------------
1. Login as student already enrolled in a course.
2. Open that course.
3. Review form must appear.
4. Submit 1–5 stars + text.
5. Refresh: review remains.
6. Submit again: same review updates, no duplicate.

TEST STUDENT DASHBOARD
----------------------
Open:
/student

Expected:
- My courses total
- Unread alerts
- Payments count
- Certificates count
- Continue Learning cards

TEST LEARNING
-------------
- Open recorded course.
- Last lesson restore still works.
- Previous / Next works.
- MP4 video reaching the end marks lesson complete.
- Existing manual "complete lesson" still works.
- Attachments open if a file is attached.

TEST ADMIN MOBILE
-----------------
Open Admin from a mobile-sized browser.
Expected:
- Logout icon is visible in Admin header.
- It logs out correctly.
- Desktop sidebar logout remains available.

REGRESSION
----------
Do NOT close Sprint unless these still work:
- Register/Login
- Free enrollment
- Paid checkout + receipt
- Admin approve/reject payment
- Notifications
- Admin students
- Exams
- Certificate + QR verification
- Profile
- Arabic/English
- Mobile

FINAL WINDOWS BUILD
-------------------
npm run build

GITHUB AFTER SUCCESS ONLY
-------------------------
git add .
git commit -m "Sprint 6 Udemy experience wishlist reviews dashboard mobile fixes"
git push

ROLLBACK SOURCE
---------------
If UI fails:
Remove-Item ".\src" -Recurse -Force
Copy-Item ".\src-before-s6" ".\src" -Recurse -Force
npm run dev

Note: The SQL tables may remain safely even after source rollback because they are additive
and do not change existing academy tables.
