SPRINT 4 — CERTIFICATE A4 LANDSCAPE PRINT FIX
=============================================
المشكلة:
الشهادة كانت أكبر من مساحة الطباعة الفعلية، لذلك المتصفح يقسمها على ورقتين.

الإصلاح:
- A4 Landscape إجباري.
- 297mm × 210mm.
- صفحة واحدة فقط.
- إخفاء أزرار الشاشة أثناء الطباعة.
- منع page-break داخل الشهادة.
- الحفاظ على الشعار وQR والألوان.

لا يوجد SQL.

التثبيت:
cd C:\projects\basmat-academy

Expand-Archive -Path "$env:USERPROFILE\Downloads\SPRINT-4-CERTIFICATE-A4-LANDSCAPE-FIX.zip" -DestinationPath "C:\projects\basmat-academy" -Force

npm run dev

الاختبار:
1. افتح شهادة.
2. اضغط طباعة / حفظ PDF.
3. اختر Paper size = A4.
4. Layout = Landscape.
5. Scale = Default أو 100%.
6. Margins = None.
7. فعّل Background graphics إذا أردت كل تفاصيل التصميم.
8. Preview يجب أن يظهر 1 page فقط.

بعد النجاح:
npm run build
git add .
git commit -m "Fix certificate A4 landscape single page printing"
git push
