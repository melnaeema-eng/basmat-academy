هذا Sprint بصري/تجربة استخدام ولا يحتاج SQL.

يشمل:
- Design System موحد: Navy + Orange + Green accents وخلفيات محايدة.
- خط Cairo عربي موحد.
- Cards / Buttons / Inputs / spacing موحدة.
- صور الدورات 16:9 وobject-cover.
- Hero جديد بهوية الأكاديمية.
- Course Cards احترافية ومتجاوبة.
- Navbar أكثر هدوءاً وتناسقاً.
- Admin Layout حديث ومتجاوب.
- Learning Player: قائمة دروس + فيديو 16:9 + السابق/التالي + progress + حفظ آخر درس محلياً.

التثبيت:
Ctrl+C
cd C:\projects\basmat-academy
Expand-Archive -Path "$env:USERPROFILE\Downloads\SPRINT-5-UIUX-LEARNING.zip" -DestinationPath "C:\projects\basmat-academy" -Force
npm run dev

الاختبار:
1) Home: الهوية والصورة والأزرار متناسقة Desktop/Mobile.
2) Courses: كل الصور 16:9 والبطاقات بنفس الارتفاع تقريباً.
3) Navbar: Desktop + Mobile + قائمة الطالب تعمل.
4) Admin: sidebar Desktop وشريط مناسب Mobile؛ كل الروابط القديمة تعمل.
5) Learning: افتح دورة مسجلة؛ الفيديو ظاهر؛ السابق/التالي يعمل؛ تم إكمال الدرس يعمل؛ Progress يتغير.
6) اخرج من صفحة التعلم وارجع: آخر درس فتحته يجب أن يعود تلقائياً.
7) Regression: Profile / Exams / Certificates / Notifications / Payments / Students.
8) npm run build
