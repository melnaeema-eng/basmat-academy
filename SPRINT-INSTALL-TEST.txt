SPRINT 5.1 — VISUAL REDESIGN
============================
الهدف: معالجة الألوان والخلفيات والصورة الرئيسية بدون تغيير وظائف الأكاديمية.

التغييرات:
- Hero جديد بصورة ICT/Data Center مناسبة، بدون نصوص مدمجة داخل الصورة.
- خلفية بيضاء/رمادية هادئة بدل المساحات الملونة الثقيلة.
- كحلي للعناوين، برتقالي للأزرار الأساسية، أخضر كلون مساعد فقط.
- إعادة ترتيب Home: Hero > Specializations > Featured Courses > Stats > Why Us > CTA.
- توحيد Course Cards والصور 16:9.
- تقليل الظلال والتدرجات وتحسين المسافات.
- تصميم Responsive.

لا يوجد SQL.

التثبيت:
Ctrl+C
cd C:\projects\basmat-academy
Expand-Archive -Path "$env:USERPROFILE\Downloads\SPRINT-5-1-VISUAL-REDESIGN.zip" -DestinationPath "C:\projects\basmat-academy" -Force
npm run dev

الاختبار:
1) Home على شاشة Desktop: Hero واضح ومتوازن ولا توجد خلفيات ثقيلة.
2) Mobile: الصورة والنص والأزرار لا تتداخل.
3) صور الدورات كلها 16:9 ولا تتمدد.
4) الألوان الأساسية: Navy + Orange، والأخضر محدود.
5) تأكد أن Courses/Login/Register/Navbar ما زالت تعمل.
6) npm run build
