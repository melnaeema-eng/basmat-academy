SPRINT 5.4 — UDEMY-STYLE STABLE REDESIGN
========================================

IMPORTANT
---------
- Built on the recovered stable source, NOT on broken Sprint 5.3.
- NO SQL.
- NO database changes.
- NO new npm dependency in this Sprint.
- Existing qrcode package from certificate recovery is still required.

WHAT CHANGED
------------
1. Unified visual system for internal pages.
2. Admin redesigned:
   Dashboard / Courses / Students / Payments / Certificates.
3. Course actions now use real icons with tooltips:
   View / Lessons / Exams / Edit / Delete.
4. Dashboard counts students from profiles (not the old students table).
5. Arabic / English support extended to the new Home, student and Admin UI.
6. RTL/LTR follows selected language.
7. Phone, email, amount, payment reference and certificate numbers stay LTR.
8. Course catalog now has Search + Category filter, closer to a marketplace layout.
9. My Courses redesigned with progress cards and Continue Learning.
10. Profile / Payments / Notifications / Contact redesigned consistently.
11. Existing payment, enrollment, lesson, exam and certificate logic is preserved.

PRE-INSTALL SAFETY
------------------
Stop the server first: Ctrl + C

cd C:\projects\basmat-academy

Make a full source backup:
Copy-Item ".\src" ".\src-before-s54" -Recurse -Force

Make sure QR dependency still exists:
Test-Path ".\node_modules\qrcode\package.json"

Expected: True
If False:
npm install qrcode

INSTALL
-------
Expand-Archive -Path "$env:USERPROFILE\Downloads\SPRINT-5-4-UDEMY-STYLE-STABLE.zip" -DestinationPath "C:\projects\basmat-academy" -Force

RUN
---
npm run dev
