SPRINT 4 — LUXURY CERTIFICATE + QR VERIFY
========================================
يشمل:
- شعار الأكاديمية من src/assets/images/logo.png
- تصميم شهادة فاخر
- QR محلي داخل المتصفح
- صفحة تحقق عامة /verify/:token
- رقم شهادة + تاريخ + مدرب
- Active / Revoked
- إلغاء/إعادة تفعيل من Admin

1) PowerShell:
cd C:\projects\basmat-academy
Expand-Archive -Path "$env:USERPROFILE\Downloads\SPRINT-4-CERTIFICATE-UPGRADE.zip" -DestinationPath "C:\projects\basmat-academy" -Force

2) تثبيت QR package:
npm install qrcode

3) Supabase SQL Editor:
شغّل supabase\SPRINT-4-CERTIFICATE-UPGRADE.sql

4) npm run dev

الاختبار:
- الطالب > شهاداتي > عرض الشهادة.
- يجب ظهور الشعار والتصميم وQR.
- امسح QR بالموبايل (عند النشر على الدومين سيشير للدومين العام؛ localhost يعمل فقط على نفس الجهاز).
- صفحة /verify/<token> يجب أن تعرض اسم الطالب، الدورة، الرقم، التاريخ، والحالة.
- Admin > الشهادات > إلغاء.
- أعد فتح رابط QR: يجب أن يظهر "الشهادة ملغاة".
- أعد التفعيل واختبر مرة أخرى.
- طباعة / حفظ PDF وتأكد أن عناصر الأزرار لا تظهر في الطباعة.

بعد النجاح:
npm run build
git add .
git commit -m "Upgrade certificates with luxury design QR verification"
git push
