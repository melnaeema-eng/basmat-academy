SCHOOL S16 BIG — OPERATIONAL SETUP
==================================

الهدف:
------
تشغيل المدرسة ببيانات فعلية بعد تثبيت الأمن والصلاحيات في S15.

يشمل:
------
1) توزيع الطلاب على الفصول.
2) نقل طالب من فصل إلى فصل متوافق.
3) توزيع جماعي لعدة طلاب.
4) منع التوزيع إذا:
   - العام مختلف.
   - الصف مختلف.
   - المنهج مختلف.
   - الفصل ممتلئ.
5) إسناد المعلم إلى:
   - فصل.
   - مادة.
   - عام دراسي.
   - صف.
   - منهج.
6) المادة لا تظهر للمعلم إلا إذا كانت مفعلة لذلك الصف/المنهج/العام.
7) إلغاء تكليف المعلم = Deactivate، وليس حذفًا نهائيًا.
8) Audit Log لعمليات توزيع الطلاب وتكليف المعلمين.
9) شاشة إشغال الفصول.
10) Health Check تشغيلي.

-------
/school/admin/operations-setup

EXPECTED BEFORE DISTRIBUTION:
-----------------------------
school_s16_health

في الحالة الحالية المتوقعة تقريبًا:
- active_enrollments = 3
- unassigned_enrollments = 3
- active_teachers = 1
- teachers_without_assignments = 1
- active_teacher_assignments = 0
- over_capacity_sections = 0

ثم:
npm run dev

TEST A — DISTRIBUTE STUDENTS:
-----------------------------
افتح:
/school/admin/operations-setup

1. اختر "توزيع الطلاب".
2. اختر الفصل المستهدف.
3. ستظهر فقط التسجيلات التي تطابق:
   نفس العام + نفس الصف + نفس المنهج.
4. اختر طالبًا أو عدة طلاب.
5. اضغط توزيع.

Expected:
- الطالب ينتقل للفصل.
- العدد داخل الفصل يزيد.
- لا يمكن تجاوز Capacity.
- لا يمكن وضع طالب في صف/منهج/عام مختلف.

بعد توزيع الثلاثة:
شغّل:
select public.school_s16_health();

Expected:
unassigned_enrollments = 0

TEST B — TEACHER ASSIGNMENT:
----------------------------
من نفس الصفحة:
"إسناد المعلمين"

1. اختر المعلم.
2. اختر الفصل.
3. اختر المادة.
4. اضغط حفظ التكليف.

Expected:
- التكليف يظهر في القائمة.
- teacher assignment count يزيد.
- Teacher Portal يبدأ بعرض الفصل/الطلاب للمادة المسندة.

بعد إسناد مادة واحدة على الأقل:
select public.school_s16_health();

Expected:
teachers_without_assignments = 0
active_teacher_assignments >= 1

-----------------
- الطلاب النشطون موزعون على فصول فعلية.
- لا يوجد Active Enrollment بدون Class.
- المعلم لديه Assignment فعلي.
- Teacher Portal يرى فقط الفصل/المادة المسموحين.
- Capacity validation يعمل.
- لا يوجد Hard Delete للتكليف.
