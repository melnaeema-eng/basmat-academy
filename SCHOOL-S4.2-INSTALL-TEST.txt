SCHOOL S4.2 — ADMIN EDIT EVERYTHING
====================================
Nawabigh Aljazeera School | نوابغ الجزيرة

الهدف:
------
إضافة زر "تعديل" بصورة موحدة إلى بيانات المدرسة التي يجب أن يمكن للإدارة تصحيحها
بدون حذف السجلات أو إعادة إنشائها.

تمت إضافة/توسيع التعديل في:
----------------------------
1. السنوات الدراسية
   /school/admin/years
   - الاسم
   - البداية والنهاية
   - الحالة
   - العام الحالي

2. المراحل + الصفوف/المستويات + المناهج
   /school/admin/structure
   - تعديل اسم المرحلة عربي/إنجليزي
   - الرمز والترتيب
   - تفعيل/تعطيل
   - تعديل الصف/المستوى ومرحلته
   - تعديل اسم المنهج ولغة التدريس
   - لا يتم حذف البيانات المرتبطة

3. المواد
   /school/admin/subjects
   - اسم المادة عربي/إنجليزي
   - الرمز
   - الوصف
   - تفعيل/تعطيل
   - تعديل توزيع المادة على المستوى والمنهج
   - الحصص الأسبوعية
   - درجة النجاح والدرجة القصوى

4. الفصول
   /school/admin/classes
   - العام
   - المستوى
   - المنهج
   - اسم الفصل A/B/C
   - السعة
   - تفعيل/تعطيل

5. الطلاب
   /school/admin/students
   - بيانات الطالب الموجودة في S3.3
   - Email / Auth User ID
   - الحالة
   - إضافة: تعديل التسجيل الأكاديمي نفسه
     العام + الصف + المنهج + الفصل + الحالة

6. أولياء الأمور
   /school/admin/parents
   - البيانات الأساسية
   - Email إلزامي
   - Auth User ID
   - إضافة: تعديل صلة ولي الأمر بالطالب

7. المعلمون
   /school/admin/teachers
   - الاسم
   - التخصص والمؤهل
   - الجوال والبريد
   - Auth User ID
   - الحالة
   - تعديل توزيع المادة للمعلم
   - تفعيل/تعطيل توزيع المادة

8. معلم الصف
   /school/admin/class-teachers
   - تعديل المعلم
   - الدفعة
   - العام الحالي
   - الصف الحالي P1/P2/P3
   - سنة الدورة 1/2/3
   - الفصل
   - الحالة
   هذا يحافظ على قاعدة المنهج العربي:
   نفس معلم الصف يرافق الدفعة من أول إلى ثالث ابتدائي.

9. الجدول الدراسي
   /school/admin/timetable
   - تعديل الحصة الموجودة
   - اليوم
   - رقم الحصة
   - الوقت
   - المعلم
   - المادة
   - الفصل
   - الغرفة/الرابط
   - التفعيل

10. الواجبات
    /school/admin/assignments
    - تعديل الواجب
    - النص
    - الفصل
    - المادة
    - المعلم
    - موعد التسليم
    - الدرجة
    - نشر/إخفاء

11. خطط الرسوم
    /school/admin/finance
    - زر تعديل للخطة
    - الرسوم السنوية
    - رسوم التسجيل
    - الرسوم الأخرى
    - عدد الأقساط
    - لا يسمح أثناء التعديل بتغيير العام/الصف/المنهج حتى لا تنشأ خطة جديدة بالخطأ

12. الامتحانات
    /school/admin/exams
    - تعديل فترة الامتحانات
    - تعديل الامتحان نفسه
    - التاريخ والوقت
    - المادة والفصل
    - المعلم
    - الدرجة ودرجة النجاح
    - المنع المالي
    - حالة النشر
    - يحتفظ بإصلاح الفلترة:
      المنهج → الصف/المستوى → الفصل → المادة

سجلات لا نعدلها مباشرة:
-----------------------
للحفاظ على Audit Trail، لا يوجد "تعديل حر" للآتي:
- الدفعات المالية المنفذة
- درجات/نتائج منشورة عبر تعديل قاعدة البيانات مباشرة
- الحركات المحاسبية المستقبلية
- الرواتب بعد الصرف

هذه تُصحح لاحقًا بواسطة:
Adjustment / Reversal / Refund / Audit Entry
بدل تغيير التاريخ المالي القديم.

SQL:
----
لا يوجد SQL جديد في S4.2.
يعتمد على RLS وصلاحيات School Admin الموجودة بالفعل.

INSTALL
-------
1) Ctrl+C

2) PowerShell:
cd C:\projects\basmat-academy

Copy-Item ".\src" ".\src-before-school-s42" -Recurse -Force

Expand-Archive -Path "$env:USERPROFILE\Downloads\SCHOOL-S4.2-ADMIN-EDIT-EVERYTHING.zip" -DestinationPath "C:\projects\basmat-academy" -Force

3) شغّل:
npm run dev

TEST
----
اختبر زر Edit في:

/school/admin/structure
- عدّل اسم صف ثم احفظ.
- أعده للاسم الصحيح للتأكد من أن Update وليس Insert.

/school/admin/classes
- عدّل Capacity.

/school/admin/subjects
- عدّل اسم/وصف مادة.
- عدّل توزيع مادة.

/school/admin/students
- عدّل الطالب.
- عدّل التسجيل الأكاديمي.

/school/admin/parents
- عدّل ولي الأمر.
- عدّل صلة القرابة.

/school/admin/teachers
- عدّل المعلم.
- عدّل توزيع مادة.

/school/admin/timetable
- عدّل وقت حصة.

/school/admin/assignments
- عدّل موعد واجب.

/school/admin/finance
- عدّل قيمة خطة رسوم.

/school/admin/exams
- عدّل امتحان موجود.
- تأكد أن فلترة المنهج/الصف/الفصل/المادة ما زالت صحيحة.
