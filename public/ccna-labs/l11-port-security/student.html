٣. جدول العناوين والإعدادات

العنصرالقيمة
PC-A192.168.10.11/24

الاختصار /24 يعني 255.255.255.0، و/30 يعني 255.255.255.252. أدخل عناوين PC من Desktop → IP Configuration، ولا تستخدم عنوان الشبكة أو البث. IPv6 /64 مستقل عن أقنعة IPv4.

٤. خطوات التنفيذ

  1. استخدم 2960 وحاسبين، ثم ping من A إلى B لتعلم MAC على Fa0/1. احفظ الإعداد مرة أخرى بعد التعلم.
  2. سجل MAC الأصلي. افصل A ووصل PC-C إضافيًا بنفس عنوان A على Fa0/1 في المختبر المعزول وولد حركة. لا تترك A وC بنفس IP متصلين معًا.
  3. أعد A الأصلي ثم أصلح المنفذ. جرّب restrict في نسخة منفصلة وقارن الحالة والعدادات.

نفذ أوامر كل جهاز في CLI الخاص به. تعليمات GUI والنصوص التفسيرية ليست أوامر IOS. اقبل اسم ملف الحفظ الافتراضي بالضغط Enter. عند اختلاف دعم أمر، وثق الإصدار والخطأ بدل الادعاء بنجاحه.

تتعلم MAC واحدة؛ الجهاز البديل يسبب violation. وضع shutdown قد ينتج secure-shutdown/err-disabled.

بعد عودة الجهاز الصحيح وإعادة تشغيل المنفذ يعود ping؛ الحفظ قبل التعلم لا يحفظ Sticky MAC لاحقة تلقائيًا.

سجل المخرجات الفعلية؛ لا تحول النتيجة المتوقعة إلى ادعاء اختبار. بعض أوامر المنصة وواجهات GUI تختلف حسب الإصدار.

Lab 11: Access-Port Security

CCNA 200-301 v1.1 • Eng. Magdi Alnaeem • 90 minutes

Packet Tracer

Download configuration TXT

1. Learning objectives and prerequisites

  • Learn sticky MACs and limit devices per port.
  • Diagnose violations and compare shutdown/restrict/protect.

Topic: 5.7 Port security

Prerequisites: IPv4, CLI and basic switching/routing; review relevant earlier labs. Workshops use the tools specified below.

Start in a new isolated lab file. These commands were not executed in Packet Tracer while preparing this package.

2. Topology, equipment and connections

Required devices/tools are identified in the execution steps. Link IDs match the port table below. Logical links are not physical cables.

LinkFromToMedium / role
L1PC-A Fa0SW1 Fa0/1Straight-through
L2PC-B Fa0SW1 Fa0/2Straight-through

3. Addressing and settings

ItemValue
PC-A192.168.10.11/24
PC-B192.168.10.12/24

IPv4 /24 means255.255.255.0 and /30 means255.255.255.252. Set PC addresses under Desktop → IP Configuration; never assign network/broadcast addresses. IPv6 /64 is separate from IPv4 masks.

4. Execution steps

  1. Use one 2960 and two PCs. Ping A→B to learn the Fa0/1 MAC, then save configuration again.
  2. Record the original MAC. Disconnect A and connect an extra PC-C with A’s IP to Fa0/1 in the isolated lab and generate traffic. Never keep A/C connected with duplicate IPs.
  3. Reconnect original A and recover the port. Try restrict in a separate copy and compare state/counters.

Run each device block on that device. GUI instructions and explanatory text are not IOS commands. Press Enter to accept the default save filename. If a command is unsupported, document the image/error rather than claiming success.

PC-A

ping 192.168.10.12

One MAC is learned; a replacement device causes a violation. Shutdown mode can show secure-shutdown/err-disabled.

After reconnecting the correct PC and recovering the port, ping succeeds. Saving before learning does not automatically persist later sticky MACs.

Record actual outputs; expected results are not test execution claims. Some commands and GUI labels vary by platform/release.
