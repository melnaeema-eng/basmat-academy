١. أهداف التعلم والمتطلبات

  • ضبط Global وLink-local، وتشغيل SLAAC.
  • إعداد مسارات IPv6 للشبكة والافتراضي والمضيف والاحتياطي.

الموضوع: 1.8,1.9,3.3 IPv6 addressing and static routes

المتطلبات: IPv4 وCLI وأساسيات VLAN والتوجيه؛ راجع المختبرات السابقة المناسبة. للورش استخدم الأدوات المحددة أدناه.

ابدأ بملف مختبر جديد معزول. لم تُشغّل هذه الأوامر على Packet Tracer ضمن إعداد الحزمة.

٤. خطوات التنفيذ

  1. استخدم راوترين 2911 وحاسبين. اختر IPv6 Auto Config على الحاسبين وسجل العناوين المتولدة بدل افتراض Interface ID محدد.
  2. افحص SLAAC وRS/RA وNS/NA في Simulation إن كانت الرسائل مدعومة. ميّز Global وLink-local وMulticast؛ عنوان ULA مثال fd00:10::/64 ولا تضفه للإعداد الحالي.
  3. اختبر الاتصال بين الحاسبين ثم أغلق R1 Gi0/1 وراقب انتقال /64 إلى AD 200. أعد فتح المنفذ بعد التجربة.

نفذ أوامر كل جهاز في CLI الخاص به. تعليمات GUI والنصوص التفسيرية ليست أوامر IOS. اقبل اسم ملف الحفظ الافتراضي بالضغط Enter. عند اختلاف دعم أمر، وثق الإصدار والخطأ بدل الادعاء بنجاحه.

1. Learning objectives and prerequisites

  • Configure global/link-local addressing and SLAAC.
  • Configure IPv6 network, default, host and floating routes.

Topic: 1.8,1.9,3.3 IPv6 addressing and static routes

Prerequisites: IPv4, CLI and basic switching/routing; review relevant earlier labs. Workshops use the tools specified below.

Start in a new isolated lab file. These commands were not executed in Packet Tracer while preparing this package.

IPv4 /24 means255.255.255.0 and /30 means255.255.255.252. Set PC addresses under Desktop → IP Configuration; never assign network/broadcast addresses. IPv6 /64 is separate from IPv4 masks.

4. Execution steps

  1. Use two 2911 routers and two PCs. Select IPv6 Auto Config and record generated addresses rather than assuming an interface ID.
  2. Inspect SLAAC RS/RA and NS/NA in Simulation when supported. Distinguish global, link-local and multicast addresses; fd00:10::/64 is a ULA example, not part of this configuration.
  3. Test both PCs, shut R1 Gi0/1 and observe the /64 route using AD 200. Restore the link afterwards.

Run each device block on that device. GUI instructions and explanatory text are not IOS commands. Press Enter to accept the default save filename. If a command is unsupported, document the image/error rather than claiming success.
