١. أهداف التعلم والمتطلبات

  • ضبط خادم وعميل NTP وفهم التزامن.
  • ربط Syslog والتعرف على SNMP وSeverity.

الموضوع: 4.2,4.4,4.5 Time and monitoring

المتطلبات: IPv4 وCLI وأساسيات VLAN والتوجيه؛ راجع المختبرات السابقة المناسبة. للورش استخدم الأدوات المحددة أدناه.

ابدأ بملف مختبر جديد معزول. لم تُشغّل هذه الأوامر على Packet Tracer ضمن إعداد الحزمة.

٣. جدول العناوين والإعدادات

العنصرالقيمة
R1192.168.99.1/24

Syslog/SNMP Server192.168.99.20/24; gateway .1

الاختصار /24 يعني 255.255.255.0، و/30 يعني 255.255.255.252. أدخل عناوين PC من Desktop → IP Configuration، ولا تستخدم عنوان الشبكة أو البث. IPv6 /64 مستقل عن أقنعة IPv4.

٤. خطوات التنفيذ

  1. استخدم راوترين 2911 و2960 وServer-PT. فعّل Syslog في Server Services. اضبط ساعة R1 يدويًا بأمر clock set والتاريخ الحالي قبل انتظار NTP.
  2. انتظر عدة دورات Polling وافحص NTP؛ مجرد وجود ntp server في running-config لا يثبت التزامن.
  3. ولّد رسالة بتبديل R2 Gi0/1 غير المستخدم shutdown/no shutdown ثم راقب Syslog دون قطع منفذ الإدارة.
  4. لـSNMP استخدم MIB Browser إن كان متاحًا في المنصة أو عميل مختبري snmpget v2c لقراءة sysName OID 1.3.6.1.2.1.1.5.0 من R1. لا تعتبر عدم وجود العميل فشلًا للخدمة.

نفذ أوامر كل جهاز في CLI الخاص به. تعليمات GUI والنصوص التفسيرية ليست أوامر IOS. اقبل اسم ملف الحفظ الافتراضي بالضغط Enter. عند اختلاف دعم أمر، وثق الإصدار والخطأ بدل الادعاء بنجاحه.

Lab 16: NTP, Syslog and SNMP Monitoring

CCNA 200-301 v1.1 • Eng. Magdi Alnaeem • 90 minutes

Packet Tracer

Download configuration TXT

1. Learning objectives and prerequisites

  • Configure an NTP server/client and interpret synchronization.
  • Send syslog and interpret SNMP and severity levels.

Topic: 4.2,4.4,4.5 Time and monitoring

Prerequisites: IPv4, CLI and basic switching/routing; review relevant earlier labs. Workshops use the tools specified below.

Start in a new isolated lab file. These commands were not executed in Packet Tracer while preparing this package.

3. Addressing and settings

ItemValue
R1192.168.99.1/24
R2192.168.99.2/24
Syslog/SNMP Server192.168.99.20/24; gateway .1

IPv4 /24 means255.255.255.0 and /30 means255.255.255.252. Set PC addresses under Desktop → IP Configuration; never assign network/broadcast addresses. IPv6 /64 is separate from IPv4 masks.

4. Execution steps

  1. Use two 2911s, a 2960 and Server-PT. Enable Syslog under Server Services. Set R1 clock manually using clock set and the current date before waiting for NTP.
  2. Allow several polling cycles and inspect NTP; an ntp server line alone does not prove synchronization.
  3. Generate a message by toggling unused R2 Gi0/1 shutdown/no shutdown; do not interrupt the management link.
  4. For SNMP use the platform MIB Browser if available, or a lab snmpget v2c client, reading R1 sysName OID 1.3.6.1.2.1.1.5.0. An absent client is not proof of server failure.

Run each device block on that device. GUI instructions and explanatory text are not IOS commands. Press Enter to accept the default save filename. If a command is unsupported, document the image/error rather than claiming success.
