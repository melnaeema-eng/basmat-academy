Packet Tracer

تحميل أوامر الإعداد TXT

١. أهداف التعلم والمتطلبات

  • تمييز العنوان الافتراضي عن عنوان الراوتر الفعلي.
  • اختبار Active/Standby وPreemption.

الموضوع: 3.5 First-hop redundancy concepts

المتطلبات: IPv4 وCLI وأساسيات VLAN والتوجيه؛ راجع المختبرات السابقة المناسبة. للورش استخدم الأدوات المحددة أدناه.

ابدأ بملف مختبر جديد معزول. لم تُشغّل هذه الأوامر على Packet Tracer ضمن إعداد الحزمة.

٢. المخطط والأجهزة والتوصيلات

الأجهزة والأدوات مذكورة في خطوات التنفيذ؛ معرفات L تقابل جدول المنافذ أدناه. الوصلات المسماة Logical لا تمثل كابلات فعلية.

٣. جدول العناوين والإعدادات

العنصرالقيمة

الاختصار /24 يعني 255.255.255.0، و/30 يعني 255.255.255.252. أدخل عناوين PC من Desktop → IP Configuration، ولا تستخدم عنوان الشبكة أو البث. IPv6 /64 مستقل عن أقنعة IPv4.

٤. خطوات التنفيذ

  1. استخدم ثلاثة 2911 و2960 وPC. انتظر انتخاب HSRP وسجل Active وStandby وعنوان MAC الافتراضي.
  2. اختبر الهدف البعيد، ثم أطفئ R1 بالكامل في نسخة المختبر، وليس وصلة LAN فقط، لكي يسقط أيضًا مسار العودة الأساسي على R3.
  3. بعد انتقال الدور إلى R2، أعد R1 وراقب preempt. ناقش لماذا سقوط WAN وحده لا يغير دور HSRP دون tracking مناسب.

نفذ أوامر كل جهاز في CLI الخاص به. تعليمات GUI والنصوص التفسيرية ليست أوامر IOS. اقبل اسم ملف الحفظ الافتراضي بالضغط Enter. عند اختلاف دعم أمر، وثق الإصدار والخطأ بدل الادعاء بنجاحه.

قد تفقد بعض الحزم أثناء مؤقتات الانتقال. HSRP لا يصلح تلقائيًا كل مسار بعيد أو جدار ناري أو Session.

Lab 19: HSRP and First-Hop Gateway Redundancy

CCNA 200-301 v1.1 • Eng. Magdi Alnaeem • 90 minutes

Packet Tracer

Download configuration TXT

1. Learning objectives and prerequisites

  • Distinguish a virtual gateway from physical router addresses.
  • Test active/standby roles and preemption.

Topic: 3.5 First-hop redundancy concepts

Prerequisites: IPv4, CLI and basic switching/routing; review relevant earlier labs. Workshops use the tools specified below.

Start in a new isolated lab file. These commands were not executed in Packet Tracer while preparing this package.

IPv4 /24 means255.255.255.0 and /30 means255.255.255.252. Set PC addresses under Desktop → IP Configuration; never assign network/broadcast addresses. IPv6 /64 is separate from IPv4 masks.

4. Execution steps

  1. Use three 2911 routers, a 2960 and PC. Wait for HSRP election and record active/standby and virtual MAC.
  2. Test the remote target, then power off R1 entirely in the lab copy, not just its LAN interface, so R3’s primary return path also fails.
  3. After R2 takes over, restore R1 and observe preemption. Discuss why WAN-only failure need not change HSRP without suitable tracking.

Run each device block on that device. GUI instructions and explanatory text are not IOS commands. Press Enter to accept the default save filename. If a command is unsupported, document the image/error rather than claiming success.

R3

show ip route

PC-A

ping 192.168.10.1
ping 203.0.113.10

R1 is active at 110, R2 standby at 100; after R1 fails, R2 becomes active without changing the client gateway.

Some packets may be lost during failover timers. HSRP does not automatically repair every remote route, firewall state or session.

Record actual outputs; expected results are not test execution claims. Some commands and GUI labels vary by platform/release.
