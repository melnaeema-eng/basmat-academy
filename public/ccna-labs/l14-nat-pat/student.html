١. أهداف التعلم والمتطلبات

  • تحديد inside/outside وقراءة الترجمات.

الموضوع: 4.1 Inside-source NAT

المتطلبات: IPv4 وCLI وأساسيات VLAN والتوجيه؛ راجع المختبرات السابقة المناسبة. للورش استخدم الأدوات المحددة أدناه.

ابدأ بملف مختبر جديد معزول. لم تُشغّل هذه الأوامر على Packet Tracer ضمن إعداد الحزمة.

٣. جدول العناوين والإعدادات

العنصرالقيمة
PC-A192.168.10.10/24; gateway .1
Server192.168.10.20/24; gateway .1
R1 inside / outside192.168.10.1/24 / 198.51.100.2/29
ISP link / Lo0198.51.100.1/29 / 203.0.113.10/32

الاختصار /24 يعني 255.255.255.0، و/30 يعني 255.255.255.252. أدخل عناوين PC من Desktop → IP Configuration، ولا تستخدم عنوان الشبكة أو البث. IPv6 /64 مستقل عن أقنعة IPv4.

٤. خطوات التنفيذ

  1. استخدم راوترين 2911 وسويتش وحاسب وServer-PT. عناوين 198.51.100.0 و203.0.113.0 توثيقية لمحاكاة ISP وليست خدمة إنترنت فعلية.
  2. من ISP اختبر ping إلى 198.51.100.3 ثم من PC-A إلى 203.0.113.10. افحص الترجمات أثناء الحركة، فبعضها ينتهي سريعًا.
  3. قبل PAT انتظر انتهاء الترجمات الديناميكية القديمة؛ إن رفض IOS إزالة القاعدة لوجود استخدام، في هذا المختبر المعزول فقط يمكن clear ip nat translation * ثم إعادة إزالة قاعدة الـPool وتطبيق PAT. احتفظ بالترجمة الثابتة.

نفذ أوامر كل جهاز في CLI الخاص به. تعليمات GUI والنصوص التفسيرية ليست أوامر IOS. اقبل اسم ملف الحفظ الافتراضي بالضغط Enter. عند اختلاف دعم أمر، وثق الإصدار والخطأ بدل الادعاء بنجاحه.

1. Learning objectives and prerequisites

  • Identify inside/outside and interpret translations.
  • Compare static NAT, dynamic pools and overload.

Topic: 4.1 Inside-source NAT

Prerequisites: IPv4, CLI and basic switching/routing; review relevant earlier labs. Workshops use the tools specified below.

Start in a new isolated lab file. These commands were not executed in Packet Tracer while preparing this package.

2. Topology, equipment and connections

Required devices/tools are identified in the execution steps. Link IDs match the port table below. Logical links are not physical cables.

3. Addressing and settings

ItemValue
PC-A192.168.10.10/24; gateway .1
Server192.168.10.20/24; gateway .1
R1 inside / outside192.168.10.1/24 / 198.51.100.2/29
ISP link / Lo0198.51.100.1/29 / 203.0.113.10/32

IPv4 /24 means255.255.255.0 and /30 means255.255.255.252. Set PC addresses under Desktop → IP Configuration; never assign network/broadcast addresses. IPv6 /64 is separate from IPv4 masks.

4. Execution steps

  1. Use two 2911 routers, a switch, PC and Server-PT. The documentation prefixes simulate an ISP, not a real Internet service.
  2. Ping 198.51.100.3 from ISP and 203.0.113.10 from PC-A. Inspect translations while traffic exists; some expire quickly.
  3. Before PAT let old dynamic translations expire. If IOS refuses to remove an in-use rule, only in this isolated lab clear ip nat translation * and then remove the pool mapping and apply PAT. Retain the static mapping.

Run each device block on that device. GUI instructions and explanatory text are not IOS commands. Press Enter to accept the default save filename. If a command is unsupported, document the image/error rather than claiming success.
