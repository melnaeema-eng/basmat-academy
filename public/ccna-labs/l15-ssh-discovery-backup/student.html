مختبر 15: SSH وCDP وLLDP ونسخ الإعداد

CCNA 200-301 v1.1 • المهندس مجدي النعيم • 90 دقيقة

Packet Tracer

تحميل أوامر الإعداد TXT

١. أهداف التعلم والمتطلبات

  • تشغيل SSH محلي وتأمين VTY.
  • توثيق الجيران ونسخ الإعداد عبر TFTP في المختبر.

الموضوع: 2.3,2.8,4.8,4.9,5.3 Management and SSH

المتطلبات: IPv4 وCLI وأساسيات VLAN والتوجيه؛ راجع المختبرات السابقة المناسبة. للورش استخدم الأدوات المحددة أدناه.

ابدأ بملف مختبر جديد معزول. لم تُشغّل هذه الأوامر على Packet Tracer ضمن إعداد الحزمة.

الأجهزة والأدوات مذكورة في خطوات التنفيذ؛ معرفات L تقابل جدول المنافذ أدناه. الوصلات المسماة Logical لا تمثل كابلات فعلية.

٣. جدول العناوين والإعدادات

العنصرالقيمة
R1192.168.99.1/24
SW1 VLAN1192.168.99.2/24; gateway .1
Admin-PC192.168.99.10/24; gateway .1
TFTP Server192.168.99.20/24; gateway .1

الاختصار /24 يعني 255.255.255.0، و/30 يعني 255.255.255.252. أدخل عناوين PC من Desktop → IP Configuration، ولا تستخدم عنوان الشبكة أو البث. IPv6 /64 مستقل عن أقنعة IPv4.

٤. خطوات التنفيذ

  1. استخدم 2911 و2960 وPC وServer-PT. كلمات المرور المعروضة للاختبار المعزول فقط. لا تضع كلمات حساباتك الحقيقية في ملف التسليم.
  2. ولّد RSA بعد hostname وdomain-name، وأدخل 2048 عند المطالبة. إن كانت الصورة لا تدعم الطول فاستخدم صورة حديثة بدل خفض أمان إنتاج.
  3. فعّل TFTP على Server → Services. استخدم copy running-config tftp: وأدخل 192.168.99.20 واسم R1-backup.cfg عند المطالبة. لا تنفذ restore على إنتاج.
  4. قارن CDP وLLDP بالمنافذ الفيزيائية، ثم ناقش لماذا قد يُعطلان على منافذ غير موثوقة وفق السياسة.

نفذ أوامر كل جهاز في CLI الخاص به. تعليمات GUI والنصوص التفسيرية ليست أوامر IOS. اقبل اسم ملف الحفظ الافتراضي بالضغط Enter. عند اختلاف دعم أمر، وثق الإصدار والخطأ بدل الادعاء بنجاحه.

R1

show users
copy running-config tftp:

Admin-PC

SSH يعمل باستخدام المستخدم المحلي؛ Telnet غير مسموح على VTY. يظهر الجار الموافق للتوصيل ويظهر ملف النسخ على TFTP Server.

TFTP بلا تشفير ولا مصادقة قوية؛ استخدمه فقط في المختبر. FTP التقليدي كذلك ليس قناة سرية.

سجل المخرجات الفعلية؛ لا تحول النتيجة المتوقعة إلى ادعاء اختبار. بعض أوامر المنصة وواجهات GUI تختلف حسب الإصدار.

Lab 15: SSH, CDP/LLDP Discovery and Configuration Backup

CCNA 200-301 v1.1 • Eng. Magdi Alnaeem • 90 minutes

Packet Tracer

Download configuration TXT

1. Learning objectives and prerequisites

  • Enable local SSH authentication and restrict VTY transport.
  • Document discovery neighbors and back up configuration via lab TFTP.

Topic: 2.3,2.8,4.8,4.9,5.3 Management and SSH

Prerequisites: IPv4, CLI and basic switching/routing; review relevant earlier labs. Workshops use the tools specified below.

Start in a new isolated lab file. These commands were not executed in Packet Tracer while preparing this package.

ItemValue

IPv4 /24 means255.255.255.0 and /30 means255.255.255.252. Set PC addresses under Desktop → IP Configuration; never assign network/broadcast addresses. IPv6 /64 is separate from IPv4 masks.

4. Execution steps

  1. Use a 2911, 2960, PC and Server-PT. Shown passwords are for this isolated exercise only; do not submit real account passwords.
  2. Generate RSA after setting hostname/domain-name; enter 2048 at the prompt. If unsupported, use a current image rather than weakening production security.
  3. Enable Server → Services → TFTP. Run copy running-config tftp: and enter 192.168.99.20 and R1-backup.cfg at the prompts. Do not restore to production.
  4. Compare CDP/LLDP neighbors to cabling, then discuss policy-based disabling on untrusted ports.

Run each device block on that device. GUI instructions and explanatory text are not IOS commands. Press Enter to accept the default save filename. If a command is unsupported, document the image/error rather than claiming success.
