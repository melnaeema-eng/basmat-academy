مختبر 1: انتقال آمن إلى Trunk وLACP

CCNP Enterprise • ENCOR / ENARSI • المهندس مجدي النعيم • 120 دقيقة

CML IOSv/IOSvL2 or IOS XE (licensed images)

تحميل أوامر الإعداد TXT

١. أهداف التعلم والمتطلبات

  • تشخيص اختلاف Native/Allowed VLANs وتوافق أعضاء القناة.
  • تنفيذ تغيير مرحلي مع baseline وrollback.

الموضوع: ENCOR 3.1 Layer 2 troubleshooting

المتطلبات: مستوى CCNA جيد، وCLI وVLAN والتوجيه. استخدم صورة IOS/IOS XE مرخصة تدعم الخصائص المحددة؛ تحقق من أسماء الواجهات قبل اللصق.

ابدأ بمختبر معزول وصور مرخصة تدعم الأوامر. لم تُشغّل محاكاة شبكة لهذه الحزمة. الواجهات g0/x تخص IOSv؛ قد تحتاج تغييرها إلى GigabitEthernet1/2/3 على CSR/C8000v وفق التوصيل.

٢. المخطط والأجهزة والتوصيلات

الأجهزة والأدوات مذكورة في خطوات التنفيذ؛ معرفات L تقابل جدول المنافذ أدناه. الوصلات المسماة Logical لا تمثل كابلات فعلية.

L2SW1 Gi0/1SW2 Gi0/1802.1Q/LACP
L3SW1 Gi0/2SW2 Gi0/2802.1Q/LACP
L4PC-B eth0SW2 Gi0/0Access VLAN10

٣. جدول العناوين والإعدادات

العنصرالقيمة
PC-A192.168.10.11/24; no gateway
PC-B192.168.10.12/24; no gateway
Po10Native999; allowed10,20,999

الاختصار /24 يعني 255.255.255.0، و/30 يعني 255.255.255.252. أدخل عناوين PC من Desktop → IP Configuration، ولا تستخدم عنوان الشبكة أو البث. IPv6 /64 مستقل عن أقنعة IPv4.

٤. خطوات التنفيذ

  1. استخدم صورتين IOSvL2 وحاسبين VPCS. اختبر أساسيات VLAN10 قبل القناة، ثم طبق الإعداد على الطرفين.
  2. سجل Summary وTrunk وSTP. افصل عضوًا واحدًا وتحقق من استمرار الخدمة، ثم نفذ أعطال المدرب واحدًا في كل مرة.
  3. على صورة dot1q-only قد لا يوجد أمر encapsulation؛ احذفه فقط بعد التحقق من دعم الصورة، مع بقاء نوع Trunk صحيحًا.

نفذ أوامر كل جهاز في CLI الخاص به. تعليمات GUI والنصوص التفسيرية ليست أوامر IOS. اقبل اسم ملف الحفظ الافتراضي بالضغط Enter. عند اختلاف دعم أمر، وثق الإصدار والخطأ بدل الادعاء بنجاحه.

٨. الأسئلة والتسليم والتقييم

  1. ما الدليل الذي يثبت كل هدف تعلم؟
  2. اختر عطلين: لماذا حدث العَرَض وما أقل إصلاح مبرر؟
  3. ما الذي لم تختبره المنصة، وما حدود الاستنتاج؟

التسليم: ملف topology من CML/EVE-NG أو running-config، أو النصوص/ورقة التصميم للورش، وجدول الإعدادات، ومخرجات التحقق، وتقرير عطلين. معيار عام100: الإعداد30، صحة القيم20، التحقق25، التشخيص25؛ قد يطبق المدرب توزيع التقييم الختامي المحدد في دليله.

لم تُنشأ ملفات .pkt/.pka أو صور أجهزة افتراضية ولم تُشغّل محاكاة شبكة لهذه الحزمة. أسئلة الورقة ليست اختبارًا إلكترونيًا مرتبطًا بنتيجة الدورة؛ هذا الربط ما زال غير منفذ.

Lab 1: Controlled Trunk and LACP Migration

CCNP Enterprise • ENCOR / ENARSI • Eng. Magdi Alnaeem • 120 minutes

CML IOSv/IOSvL2 or IOS XE (licensed images)

Download configuration TXT

1. Learning objectives and prerequisites

  • Troubleshoot native/allowed VLAN mismatch and channel-member consistency.
  • Execute staged changes with baseline and rollback evidence.

Topic: ENCOR 3.1 Layer 2 troubleshooting

Prerequisites: solid CCNA switching/routing and CLI skills. Use licensed IOS/IOS XE images supporting the stated features and verify interface names before pasting.

Start in an isolated lab with licensed feature-capable images. No network simulation was executed for this package. g0/x interface names target IOSv; map them to GigabitEthernet1/2/3 on CSR/C8000v as required by the cabling.

2. Topology, equipment and connections

Required devices/tools are identified in the execution steps. Link IDs match the port table below. Logical links are not physical cables.

LinkFromToMedium / role
L1PC-A eth0SW1 Gi0/0Access VLAN10
L2SW1 Gi0/1SW2 Gi0/1802.1Q/LACP
L3SW1 Gi0/2SW2 Gi0/2802.1Q/LACP
L4PC-B eth0SW2 Gi0/0Access VLAN10

3. Addressing and settings

ItemValue
PC-A192.168.10.11/24; no gateway
PC-B192.168.10.12/24; no gateway
Po10Native999; allowed10,20,999

IPv4 /24 means255.255.255.0 and /30 means255.255.255.252. Set PC addresses under Desktop → IP Configuration; never assign network/broadcast addresses. IPv6 /64 is separate from IPv4 masks.

4. Execution steps

  1. Use two IOSvL2 nodes and two VPCS clients. Verify VLAN10 before bundling, then configure both ends.
  2. Capture summary/trunk/STP, disconnect one member and verify continuity, then diagnose instructor faults one at a time.
  3. A dot1q-only image may omit encapsulation selection; remove only that command after checking image support.

Run each device block on that device. GUI instructions and explanatory text are not IOS commands. Press Enter to accept the default save filename. If a command is unsupported, document the image/error rather than claiming success.
