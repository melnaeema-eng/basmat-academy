SCHOOL SPRINT S3 BIG — NAWABIGH ALJAZEERA
==========================================

اسم المدرسة:
نوابغ الجزيرة
Nawabigh Aljazeera School

هذا Sprint كبير ويضيف طبقة التدريس اليومية فوق الطلاب/الأهل/الرسوم الموجودة في S2.

يشمل:
------
1) إدارة المعلمين
   - school_teachers
   - رقم موظف تلقائي TCH-YYYY-xxxxx
   - التخصص والمؤهل والجوال والبريد
   - ربط اختياري بحساب Auth User ID لبوابة المعلم

2) توزيع المواد
   - school_teacher_assignments
   - المعلم + العام + المستوى + المنهج + المادة + الفصل
   - إمكانية توزيع المعلم على فصل محدد أو المستوى كله

3) توزيع المواد على الصفوف
   - استخدام school_grade_subjects الموجود من S1
   - المادة + المستوى + المنهج
   - عدد الحصص الأسبوعية
   - درجة النجاح
   - الدرجة القصوى

4) الجدول الدراسي
   - school_timetable
   - الفصل + المادة + المعلم + اليوم + رقم الحصة
   - وقت البداية والنهاية
   - الغرفة/الرابط

5) الحضور والغياب
   - school_attendance_sessions
   - school_attendance_records
   - حاضر / غائب / متأخر / بعذر
   - تسجيل دفعة واحدة لجميع طلاب الفصل
   - المعلم لا يدير إلا الفصل/المادة المسندة إليه
   - School Admin يستطيع الإدارة بالكامل

6) الواجبات
   - school_assignments
   - school_assignment_submissions
   - عنوان ووصف وموعد تسليم ودرجة
   - الطالب يمكنه تسليم الواجب
   - أساس تصحيح المعلم وملاحظاته موجود في الخدمة

7) بوابة المعلم
   /school/teacher

   تعرض:
   - المواد المسندة
   - الصفوف
   - الواجبات القادمة

8) بوابة الطالب
   /school/student

   تعرض:
   - ملخص الحضور
   - الواجبات
   - حالة التسليم
   - الدرجة/ملاحظة المعلم
   - إمكانية تسليم نص الواجب

9) بوابة ولي الأمر
   /school/parent

   تعرض:
   - جميع الأبناء المرتبطين بالحساب
   - المستوى والمنهج والفصل
   - المديونية الحالية لكل ابن

10) حماية مستقلة لإدارة المدرسة
    ProtectedSchoolAdminRoute

    يقبل:
    profiles.role = admin
    أو
    profiles.school_role = school_admin

    وبالتالي School Admin لا يحتاج أن يصبح Academy Admin.

11) تثبيت إصلاح School Admin
    أي حساب role=admin يحصل school_role=school_admin عند تشغيل SQL
    حتى يصبح الإصلاح السابق جزءًا رسميًا من المشروع.

INSTALL
-------
1) أوقف السيرفر:
Ctrl+C

2) PowerShell:

cd C:\projects\basmat-academy

Copy-Item ".\src" ".\src-before-school-s3" -Recurse -Force

Expand-Archive -Path "$env:USERPROFILE\Downloads\SCHOOL-S3-BIG-TEACHERS-ATTENDANCE-PORTALS.zip" -DestinationPath "C:\projects\basmat-academy" -Force

3) Supabase > SQL Editor

شغّل فقط:

supabase\SCHOOL-S3-BIG.sql

Expected:
Success. No rows returned

4) شغّل:

npm run dev

PORTAL AUTH LINKING
-----------------------------------------
حتى يدخل المعلم/الطالب/ولي الأمر ببوابته،
يجب أن يكون لديه حساب Supabase Auth ثم تربطه من إدارة المدرسة.

المعلم:
/school/admin/teachers
ضع Auth User ID في ملف المعلم.

الطالب:
/school/admin/students
ضع Auth User ID في ملف الطالب.

ولي الأمر:
/school/admin/parents
ضع Auth User ID في ملف ولي الأمر.

هذه الخطوة مؤقتة في S3.
في Sprint لاحق سنضيف إنشاء حسابات المدرسة وإرسال كلمة مرور/دعوة آليًا.
