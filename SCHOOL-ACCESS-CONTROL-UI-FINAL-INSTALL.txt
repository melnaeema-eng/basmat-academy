SCHOOL ACCESS CONTROL UI FINAL
==============================

هذه آخر حزمة Access قبل Production.

تقوم فعليًا بـ:
- /login = الأكاديمية فقط.
- /school/login = المدرسة فقط.
- School Login يرفض أي حساب لا يملك School Role.
- Role واحد => تحويل مباشر.
- عدة Roles => /school/choose-role.
- صفحة /school/admin/access-management لإدارة صلاحيات الموظفين.
- School Admin يرى كل الإدارة.
- Finance -> Finance فقط.
- HR -> HR Center فقط.
- Admissions -> Admissions فقط.
- Student Affairs -> Student Affairs فقط.
- Teacher / Parent / Student عبر Identity Links الحالية.
- Multi-role مدعوم.
- is_school_admin أصبح يدعم school_staff_roles مع الحفاظ على profiles.school_role القديم.
